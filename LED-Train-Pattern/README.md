# LED Train Pattern – PIC18F4580

## Description

This program implements an LED train pattern using the PIC18F4580
microcontroller.

## Microcontroller

- PIC18F4580

## Concepts Used

- GPIO
- Digital switch interfacing
- PORTB control
- Bit shifting
- LED pattern generation
- Level triggering

## Source Code

The complete Embedded C source code is available in this folder.

## Output

When the switch is pressed, the selected LED train pattern runs
on the LEDs connected to PORTB.
